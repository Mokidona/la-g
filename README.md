# Лендинг «Реабилитация и ЛФК в Астане»

Сайт и панель управления на чистом Node.js — без npm-зависимостей и сборки.
Страница рендерится на сервере из `data/content.json`, поэтому все тексты,
фотографии, цены, ссылки, цвета и набор секций меняются в админке без правки кода.

## Быстрый старт

```bash
# Node.js 20+
ADMIN_PASSWORD=мой-пароль node server.js
```

- Сайт: http://localhost:3000/
- Админка: http://localhost:3000/admin

Если `ADMIN_PASSWORD` не задан, сервер сгенерирует пароль при первом запуске
и запишет его в `data/admin-password.txt`. Пароль можно сменить в админке:
**Резервная копия → Пароль администратора**.

## Редактор: правка прямо на сайте

Админка открывается как визуальный редактор: слева — слои страницы, в центре —
сам сайт, справа — свойства выбранного элемента.

- **Клик по тексту** ставит курсор в слово — печатаете и сразу видите результат.
  `Enter` или клик мимо заканчивают правку, `Esc` отменяет, `Ctrl+Z` откатывает.
- **Клик по фото** выбирает его, кнопка в панели сверху заменяет файл;
  можно просто перетащить картинку с рабочего стола на фото — оно подсветится
  пунктиром и примет файл (или заменит выбранное фото, если бросить рядом).
- **Блок** (карточка пакета, отзыв, вопрос) выделяется кликом по фону и получает
  панель `≡ + ↑ ↓ ⧉ ✕` — переставить, добавить, дублировать, удалить.
  Поменять порядок можно двумя способами: тянуть за ручку `≡` в панели или
  просто перетащить саму карточку в нужное место — появится линия вставки.
- **Секции** тоже двигаются: выделите секцию (клик по её фону или по названию
  в слоях) и перетащите за `≡` в панели, стрелками `↑ Выше / ↓ Ниже` в свойствах
  или потянув строку секции в списке слоёв. Порядок сохраняется в контенте и
  сразу меняет страницу.
- **Слои слева** повторяют структуру сайта: можно быстро перейти к секции,
  свернуть список, скрыть секцию глазом `◉`, перетащить пункт или секцию.
- **Свойства справа** показывают все поля элемента: для текста — RU и KZ
  рядом, для блока — его содержимое, позиция, дублирование и удаление,
  для секции — видимость, порядок, переход к её блокам.
- **Масштаб** — кнопки `−  54%  +  Вписать` в правом нижнем углу холста
  (клик по процентам переключает 50 / 75 / 100 %), плюс те же кнопки в верхней панели.
- **Верхняя панель** — ширина экрана (компьютер / планшет / телефон),
  язык RU/KZ, отмена и повтор, «Все настройки» и «Сохранить».
- Изменения живут в браузере, пока вы не нажмёте **Сохранить** (или `Ctrl+S`).
  Уйти со страницы с несохранёнными правками браузер не даст.

Кнопка **Все настройки** открывает полные формы — они нужны для SEO, контактов,
цветов и резервных копий:

| Раздел настроек | Что редактируется |
| --- | --- |
| Основное | title/description, логотип, телефоны, ссылки записи, WhatsApp, 2ГИС, соцсети |
| Главный экран | заголовок, подзаголовок, кнопка, фото и alt-текст |
| Диагностика | вступительная карточка и этапы (можно добавлять, менять порядок, выделять) |
| Когда заниматься | список показаний и карточка с призывом |
| Пакеты | пакеты, цены, состав (входит / зачёркнуто), кнопки, сплит-формат |
| Услуги | фото, цифра опыта, карточки услуг, ссылки «смотреть цены» |
| Специалисты | имена, фото, ссылки |
| Отзывы | имя, инициалы, оценка, текст (абзацы через пустую строку) |
| Вопросы | вопросы, ответы, раскрыт ли вопрос по умолчанию |
| Подвал сайта | подпись, меню, копирайт |
| Форма записи | тексты модального окна |
| Оформление | фирменные цвета, узор фона, видимость секций |
| Резервная копия | экспорт/импорт JSON, сброс к исходному, смена пароля |

Каждый текст хранится в двух вариантах — RU и KZ. Язык переключается на сайте
ссылками `?lang=ru` / `?lang=kz`; выбор запоминается в браузере.

В текстах можно использовать `<b>`, `<i>`, `<br>` (в том числе
`<br class="br-m">` для переноса только на мобильном). Остальные теги
экранируются.

## Данные

Всё состояние лежит в каталоге `data/` (по умолчанию — рядом с `server.js`,
в Docker — в `/data`):

| Файл | Назначение |
| --- | --- |
| `data/content.json` | текущий контент сайта |
| `data/content.backup.json` | предыдущая версия перед каждым сохранением |
| `data/admin.json` | соль и scrypt-хеш пароля администратора |
| `data/uploads/` | изображения, загруженные через админку |
| `data/admin-password.txt` | сгенерированный пароль (удаляется после смены) |

Каталог `data/` не коммитится и не попадает в Docker-образ. Для переноса настроек
используйте экспорт/импорт JSON в админке.

## Docker

```bash
docker compose up -d --build
```

- Контейнер слушает порт **3000**, Traefik проксирует на него домен
  `kinesiolife.kz` (см. `docker-compose.yml`).
- Контент, картинки и пароль сохраняются в именованном томе `landing-data`.
- Пароль задаётся переменной `ADMIN_PASSWORD` или генерируется при первом
  запуске: `docker compose logs landing`.

```bash
# если нужно посмотреть сгенерированный пароль
docker compose exec landing cat /data/admin-password.txt
```

`Caddyfile` больше не используется: заголовки безопасности, кеширование и gzip
реализованы в `server.js`. Раньше контейнер нёс только статику, теперь ему нужен
Node.js — поэтому в `docker-compose.yml` увеличен лимит памяти и изменён порт.

## Переменные окружения

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `PORT` | `3000` | порт приложения |
| `DATA_DIR` | `./data` | каталог с контентом и загрузками |
| `ADMIN_PASSWORD` | — | пароль администратора при **первом** запуске (потом хранится хеш) |

## Устройство

```
server.js              HTTP-сервер: рендер, API, авторизация, загрузки, статика
lib/default-content.js исходный контент и схема слияния
lib/render.js          серверный рендер страницы (RU/KZ) и меток для редактора
admin/index.html       каркас админки: холст, слои, свойства
admin/editor.js        визуальный редактор: выделение, правка на странице, drag&drop
admin/editor.css       стили редактора и панелей
admin/admin.js         вход, сохранение, полные формы настроек
admin/admin.css        стили форм настроек и входа
assets/                фотографии и иконки
styles.css, script.js  стили лендинга, аккордеон/модалка/язык
```

- Сессии администратора живут в памяти процесса 12 часов; после рестарта
  контейнера нужно войти заново.
- Пароль хранится как scrypt-хеш, вход ограничен 8 попытками за 15 минут.
- Загружаются только PNG, JPEG, WebP и GIF до 6 МБ.
- Сайт и админка работают по HTTPS за обратным прокси; cookie сессии получает
  флаг `Secure` по заголовку `X-Forwarded-Proto`.
