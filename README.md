# Лендинг «Реабилитация и ЛФК в Астане»

Статический сайт: `index.html` (RU), `kz.html` (KZ), `styles.css`, `script.js`
и картинки в `assets/`. Сборки, npm-зависимостей и базы данных нет — HTML
открывается напрямую и раздаётся любым статическим сервером.

Тексты и фотографии, которые были сохранены в админке, уже перенесены в эти
две страницы, поэтому сайт выглядит ровно так, как выглядел до её удаления.

## Правка контента

Тексты лежат прямо в разметке, менять их можно в любом редакторе:

- `index.html` — русская версия, `kz.html` — казахская. Правки нужно вносить
  в обе страницы, иначе языки разойдутся.
- Заголовок и описание для поисковиков — `<title>` и `<meta name="description">`.
- Телефон — ссылки `tel:+7...` (они же открывают окно записи через `script.js`),
  ссылки на WhatsApp и 2ГИС — обычные `<a href>`.
- Фотографии — файлы в `assets/`; замените файл с тем же именем или поправьте
  `src`. Ссылки на картинки относительные (`assets/...`), поэтому сайт работает
  и из подкаталога, и при открытии файла напрямую.
- Кнопки RU/KZ переключают страницы и запоминают выбор в браузере.

Стили — в `styles.css`. Цвета темы заданы переменными в `<style>` внутри
каждой страницы (`--lime`, `--purple`, `--pattern` и т. д.), узор фона —
`assets/pattern.jpg`.

## Структура

```
index.html          страница на русском
kz.html             страница на казахском
styles.css          стили лендинга
script.js           аккордеон FAQ, окно записи, переключатель языка
assets/             фотографии, иконки, узор
assets/uploads/     изображения, загруженные ранее через админку
Caddyfile           статическая раздача, кеш и заголовки безопасности
Dockerfile          образ caddy:2-alpine со статикой
docker-compose.yml  запуск за Traefik для kinesiolife.kz
```

## Локальный просмотр

```bash
python3 -m http.server 8080
# http://localhost:8080/       — RU
# http://localhost:8080/kz.html — KZ
```

## Docker

```bash
docker compose up -d --build
```

- Контейнер слушает порт **80**, Traefik проксирует на него домен
  `kinesiolife.kz` (см. `docker-compose.yml`).
- Тома и переменные окружения не нужны: всё содержимое сайта лежит в образе.
- `Caddyfile` добавляет gzip/zstd, кеш на `assets/` и заголовки безопасности;
  `/healthz` отвечает `ok` для healthcheck.

Если после правок контейнер отдаёт старую страницу, пересоберите образ —
`docker compose up -d` сам его не пересобирает:

```bash
docker compose build landing && docker compose up -d --force-recreate landing
```

`docker compose ps` должен показать `Up (healthy)`, проверить ответ можно так:

```bash
curl -I https://kinesiolife.kz/
curl -I https://kinesiolife.kz/kz.html
```
